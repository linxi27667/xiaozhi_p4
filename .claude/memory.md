# 项目修改记忆

## 2026-07-18 厦门演示适配

## 2026-07-18 设置面板硬件控制

- 亮度滑块已接入 P4 PWM 背光，拖动实时预览，松手持久化，最低限制为 10%。
- 音量滑块已接入 ES8311 输出音量，松手后应用并持久化，支持 0% 静音。
- 页面打开时读取当前硬件值，不再使用仅供显示的固定默认值。
- 新增 `ui_device_settings` C/C++ 桥接层，并修正背光预览后相同值无法保存的问题。

## 2026-07-19 人脸登录演示模式

- 人脸登录从“匹配已登记用户”调整为“检测到满足质量条件的人脸”。
- 新增检测器独立初始化入口，登录流程不再依赖 TF 卡人脸数据库，也不再自动登记首张脸。
- 使用置信度 0.65、最小尺寸 60×60、画面中央区域和连续两次检测作为解锁条件。
- 使用 ESP-IDF 5.5.3 在独立 `build_face_demo` 目录完成全量及增量构建；固件约 6.30 MiB，应用分区剩余 50%。
