当前映射是：

| 设备 | 从机数组 | 全局状态索引 | GPIO |

| 雾化器 | `relay[2]` | `[5]` | GPIO16 |
| 安防总闸 | `relay[3]` | `[6]` | GPIO17 |

你这条日志：

```text
BSP_IOT: GPIO state updated: 智慧庭院[5]=1 (origin=18)
```

这里 `[5]=1` 是 **雾化器打开**，不是水泵。`origin=18` 是十进制 `18`，也就是 `0x12 = IOT_CMD_SET_RELAY`。

如果水泵真的收到打开响应，应该看到类似：

```text
GPIO state updated: 智慧庭院[4]=1 (origin=18)
```

水泵没打开，优先查这几个点：

1. **有没有发到水泵**
   看主机日志有没有 `Water pump: ON`，从机有没有 `Relay[1] = ON`。

2. **安防总闸是否还处于切断状态**
   火灾响应里代码会：
   - `relay[3] = ON`：安防总闸切断
   - `relay[1] = OFF`：水泵关闭
   - `relay[2] = OFF`：雾化器关闭
   - 灯全部打开

   如果 `safety_switch` 还在 `ON/TRIPPED`，水泵继电器状态即使显示开，也可能实际没电。先执行 `self.garden.fire_reset`，或者确认 `safety_switch=0`。

3. **继电器是否低电平触发**
   现在代码默认 `GPIO输出1 = 继电器开`。如果你的继电器模块是常见的 **低电平触发**，那 GPIO15 输出 1 反而是关，输出 0 才是开。这个需要看继电器板的 IN 指示灯，或万用表测 GPIO15/继电器输入。

- 灯接在安防总闸前级/独立应急电源，保留现在逻辑；
- 或者火灾时真正全断电，把代码里的灯全开改成灯全关。
